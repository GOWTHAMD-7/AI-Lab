## How to Run Each Experiment

You can run each Python script directly from your terminal using Python:

```bash
# Experiment 1
python Experiment-01_Data_Preprocessing/data_preprocessing.py

# Experiment 2
python Experiment-02_BFS_and_DFS/bfs_dfs.py

# Experiment 3
python Experiment-03_Hill_Climbing_and_A_Star/hill_climbing_and_a_star.py

# Experiment 4 (Simulation demo)
python Experiment-04_Chatbot_Application/chatbot.py
# (Or interactive mode)
python Experiment-04_Chatbot_Application/chatbot.py --interactive

# Experiment 5
python Experiment-05_Inference_System/inference_system.py

# Experiment 6 (Default demonstration for N=4 and N=8)
python Experiment-06_N_Queens_Problem/n_queens.py
# (Or pass any custom N from 1 to 9)
python Experiment-06_N_Queens_Problem/n_queens.py 5
```
